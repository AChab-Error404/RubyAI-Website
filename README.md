# Ruby AI — site Web

Site public statique de Ruby AI : interface rouge/noir, mascotte et connexion
locale optionnelle. Aucun noyau Python, script PowerShell, journal ou modèle
local n'est publié dans ce dépôt.

Le site fonctionne en démonstration par défaut. Le bouton de connexion accepte
uniquement un pont HTTP local sur `127.0.0.1`.
